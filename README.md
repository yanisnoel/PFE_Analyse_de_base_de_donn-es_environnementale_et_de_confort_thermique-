# PFE_Analyse_de_base_de_donn-es_environnementale_et_de_confort_thermique-
Le projet proposé consiste en l'exploration de différentes bases de données de confort selon l'axe du vecteur mouvement d'air. L'objectif est de mieux appréhender la dynamique du confort thermique adapté à la ventilation naturelle, ventilation mécanique et climatisation en condition chaude.
